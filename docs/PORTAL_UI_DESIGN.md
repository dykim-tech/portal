## 화면 구조

포털은 왼쪽 세로 메뉴와 상단 가로 메뉴로 같은 기능에 접근한다. 넓은 화면에서는 두 메뉴를 함께 보여 주고, 좁은 화면에서는 가로 메뉴를 스크롤하며 이동한다. 현재 위치는 두 메뉴에서 함께 강조한다.

자료 관리 왼쪽 폴더 트리 글자는 가운데 목록의 이름과 같은 14px(.875rem)이다(2026-10-27). 왼쪽 메뉴는 항목 이름만 표시하고 이름 앞의 도형·아이콘은 사용하지 않는다. 메뉴 이름은 한 줄로만 표시하며(줄바꿈 없음), 왼쪽 메뉴 폭은 기본 224px(1050px 이하 화면 190px)보다 좁아지지 않는 범위에서 가장 긴 메뉴 이름(예: 'LOGIN NAS 관리자 설정')에 맞춰 자동으로 넓어진다(2026-10-26). **설정 → 메뉴 순서 편집**에서 항목별 위·아래 버튼으로 메뉴 순서를 바꾸고(상단 가로 메뉴도 같은 순서) **기본 순서로 되돌리기**로 초기화할 수 있다. 저장된 순서는 로그인 사용자 계정에 보관되어 새로고침·로그아웃 후나 다른 브라우저에서도 유지된다. 패널 이름은 **메뉴 표시·순서 편집**(2026-10-25)이다. 관리자에게는 목록 위에 '체크한 메뉴만 모든 사용자의 왼쪽·상단 메뉴에 표시' 안내, 각 행 왼쪽에 **표시** 체크 상자(초록색), 아래에 **모든 메뉴 표시** 버튼을 둔다. 체크를 해제한 행은 점선 테두리·흐린 취소선 이름과 '숨김' 표시로 바뀌고 왼쪽·상단 메뉴에서 바로 사라지며, 알림으로 '메뉴 N개를 숨겼습니다. 모든 사용자에게 적용됩니다.'를 보여 준다. '설정' 행의 체크 상자는 항상 체크된 채 비활성이다. 관리자가 아닌 사용자에게는 체크 상자 없이 보이는 메뉴만 나열한다.

메뉴: 대시보드, **회의록**, **업무기안**, 설치관리, 프로젝트 관리, 자료 관리, 자산 관리, **TO-DO List**, 업무관리, 리포트, **도구**, **Mail**, **GRACECNS**, **NAS**(묶음), 설정. **NAS**는 묶음 메뉴로, 누르면 펼쳐져(오른쪽 꺾쇠 ▾/▴) 하위 메뉴 **NAS**(https://dykim-nas.duckdns.org/), **OMV NAS 관리자**(https://omv.dykim-nas.duckdns.org/), **LOGIN NAS 관리자**(https://login.dykim-nas.duckdns.org/)가 들여 쓰기와 왼쪽 세로선으로 아래에 나타나고, 각각 새 탭에서 연다. 상단 가로 메뉴에서는 'NAS ▾'를 누르면 하위 메뉴가 그 오른쪽에 연한 배경 버튼으로 이어서 나타난다. 펼침 상태는 이 브라우저에 기억하며, 메뉴 순서·표시 설정에서는 NAS 묶음이 메뉴 하나로 다뤄진다(2026-10-26). **GRACECNS**는 화면을 바꾸지 않고 회사 홈페이지(http://gracecns.com/)를 새 탭에서 연다. **Mail**은 화면을 바꾸지 않고 이 PC에 설치된 Outlook 앱을 연다(브라우저 확인 창, 안내 알림 표시). 저장된 메뉴 순서가 있는 사용자에게는 새 메뉴를 기본 순서에서 바로 앞 메뉴 다음에 넣는다(회의록은 대시보드 다음, 앞 메뉴가 없으면 **설정** 앞). **도구** 화면은 draw.io·Excalidraw·Claude·ChatGPT·Google Drive·Notion·윌라 - 독서의 모든 것·Obsidian·Visual Studio Code를 카드로 보여 주고, 웹 도구는 새 탭에서 열며 Obsidian·Visual Studio Code는 'PC 앱 실행'으로 표시해 설치된 앱을 연다(첫 글자 표시, 상표 로고는 쓰지 않음). 관리자의 사용자 관리·백업/복구·운영관리·사용량 관리는 메뉴에 두지 않고 **설정** 화면 맨 위 **관리자 메뉴**의 바로가기 카드로 연다. 이 화면들을 여는 동안 메뉴의 설정을 강조하고 위치는 `설정 / 사용자 관리`처럼 표시한다. 상단의 알림 버튼 이름은 **알림**이다. **GitHub 저장소**는 설정 화면의 **바로가기** 카드(모든 사용자, 새 탭)로 연다. 왼쪽 메뉴 하단에는 링크 없이 계정 정보만 둔다.

왼쪽 메뉴의 마지막 항목과 하단 계정 정보 사이에는 충분한 여백을 둔다.

각 화면의 상단에는 **뒤로가기** 버튼을 두어 직전에 열었던 화면으로 돌아간다. 브라우저 뒤로가기도 같은 기록을 따르며 대시보드에서 멈추고(포털 밖으로 나가지 않음), 창이 열려 있으면 창만 닫는다. 로그인 직후 대시보드에서는 버튼을 비활성화한다.

## 디자인 기준

- 기본색은 짙은 녹색이며 흰 배경과 연한 녹색 카드로 주요 정보를 구분한다.
- 다크 모드를 지원하고 선택은 브라우저에 저장한다.
- 목록은 검색, 정렬, 페이지 크기 선택, 이전·다음 이동을 제공한다.
- 모든 표는 머리글 경계를 끌어 열 너비를 조정하고, 경계를 두 번 누르면 기본 너비로 돌아간다. 너비는 화면·표별로 브라우저에 저장한다. 저장한 너비의 합이 화면보다 넓으면(창 크기, 메뉴·고객 목록 접기) 잘리지 않도록 화면 너비에 맞춰 보여 준다(2026-10-20): 각 열은 머리글이 한 줄로 보이는 너비, 한 줄로 쓰는 칸은 내용 너비(최대 180px), 줄바꿈하는 제목 칸은 220px을 최소로 두고, 남는 너비를 같은 비율로 줄인다. 줄인 너비는 저장하지 않으며, 저장한 너비가 최소보다 좁으면 최소 너비로 넓혀 보여 준다.
- 등록과 수정은 대화창에서 처리하고 오류는 입력 창 가까이에 표시한다.
- 좁은 화면의 표는 가로로 스크롤하며, 주요 버튼은 줄바꿈되어도 사용할 수 있어야 한다.
- 조회자에게 수정·삭제 버튼을 표시하지 않으며 서버에서도 역할을 검사한다.

### 알림

자산 기한과 관리자용 업무 활동을 한 목록에서 보여 준다. 종류·제목과 함께 실제 알림 설명을 별도 줄에 표시한다. 자산 기한은 물품 보기, 업무 활동은 관련 메뉴 보기로 이동한다. 각각의 읽음 버튼은 해당 알림만 처리한다.

### 프로젝트 관리

설치 프로젝트와 기타 프로젝트를 구분한다. 설치 전·설치 중·설치 후 단계, 진행 상태, 예정/실제 일정, 고객사, 담당자, 위치, 메모를 기록한다. 저장하면 대화창을 닫고 목록을 갱신한다. 목록에서 프로젝트를 다시 열어 단계별 할 일을 추가하고 완료 상태를 표시한다. 수정 권한이 있는 사용자는 목록 오른쪽의 삭제 버튼으로 확인 후 프로젝트를 삭제할 수 있다. 기존 설치 정보와 연결할 수 있다.

### 사용량 관리

관리자 전용. 상단 카드에 드라이브 여유 공간·사용률, 포털 데이터 합계, 첨부파일 합계를 보여 준다. 로컬 드라이브 영역은 드라이브별 사용/전체/여유 용량과 막대를 표시하며 사용률 90% 이상이면 경고색으로 바꾼다(백업 폴더가 다른 드라이브에 있으면 함께 표시). 포털 데이터 파일 표는 DB·WAL·SHM·업로드 임시 폴더·실행 로그·백업 폴더의 위치와 크기를, 메뉴별 첨부파일 표는 자료 관리·설치·자산·고객·TO-DO 첨부의 파일 수와 용량을 보여 준다. **새로 고침**으로 다시 확인한다.

### 운영관리

관리자가 서버 실행 상태와 기본 데이터 건수를 확인하고, 이 화면에서 포털 설계도·화면 디자인·운영자 매뉴얼을 탭으로 읽는다. 운영자 매뉴얼 탭에서는 패널 오른쪽 위 **PDF 다운로드** 버튼을 표시한다. 백업/복구는 기존 전용 메뉴로 이동한다.
