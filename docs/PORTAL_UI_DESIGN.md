## 화면 구조

포털은 왼쪽 세로 메뉴와 상단 가로 메뉴로 같은 기능에 접근한다. 넓은 화면에서는 두 메뉴를 함께 보여 주고, 좁은 화면에서는 가로 메뉴를 스크롤하며 이동한다. 현재 위치는 두 메뉴에서 함께 강조한다.

왼쪽 메뉴는 항목 이름만 표시하고 이름 앞의 도형·아이콘은 사용하지 않는다. **설정 → 메뉴 순서 편집**에서 항목별 위·아래 버튼으로 왼쪽 메뉴 순서를 바꾸고 **기본 순서로 되돌리기**로 초기화할 수 있다. 저장된 순서는 로그인 사용자별로 해당 브라우저에 보관되며 새로고침 후에도 유지된다.

메뉴: 대시보드, 설치관리, 프로젝트 관리, 자료 관리, 자산 관리, **TO-DO List**, 업무관리, 리포트, **도구**, 설정. **도구** 화면은 draw.io·Claude·ChatGPT·Google Drive·Notion·Obsidian·Visual Studio Code를 카드로 보여 주고, 웹 도구는 새 탭에서 열며 Obsidian·Visual Studio Code는 'PC 앱 실행'으로 표시해 설치된 앱을 연다(첫 글자 표시, 상표 로고는 쓰지 않음). 관리자의 사용자 관리와 백업/복구는 메뉴에 두지 않고 **설정** 화면 맨 위 **관리자 메뉴**의 바로가기 카드로 연다. 두 화면을 여는 동안 메뉴의 설정을 강조하고 위치는 `설정 / 사용자 관리`처럼 표시한다. 상단의 알림 버튼 이름은 **알림**이다. **운영관리**와 **사용량 관리**는 왼쪽 메뉴 하단의 **GitHub 저장소** 바로 아래에 같은 링크 형태로 차례로 두고, 상단 가로 메뉴에도 표시한다.

왼쪽 메뉴의 마지막 항목과 하단 링크 사이에는 충분한 여백을 두고, GitHub 저장소·운영관리 링크는 주요 메뉴보다 작은 글자로 같은 왼쪽 기준선에 맞춰 표시한다.

각 화면의 상단에는 **뒤로가기** 버튼을 두어 직전에 열었던 화면으로 돌아간다. 브라우저 뒤로가기도 같은 기록을 따르며 대시보드에서 멈추고(포털 밖으로 나가지 않음), 창이 열려 있으면 창만 닫는다. 로그인 직후 대시보드에서는 버튼을 비활성화한다.

## 디자인 기준

- 기본색은 짙은 녹색이며 흰 배경과 연한 녹색 카드로 주요 정보를 구분한다.
- 다크 모드를 지원하고 선택은 브라우저에 저장한다.
- 목록은 검색, 정렬, 페이지 크기 선택, 이전·다음 이동을 제공한다.
- 모든 표는 머리글 경계를 끌어 열 너비를 조정하고, 경계를 두 번 누르면 기본 너비로 돌아간다. 너비는 화면·표별로 브라우저에 저장한다.
- 등록과 수정은 대화창에서 처리하고 오류는 입력 창 가까이에 표시한다.
- 좁은 화면의 표는 가로로 스크롤하며, 주요 버튼은 줄바꿈되어도 사용할 수 있어야 한다.
- 조회자에게 수정·삭제 버튼을 표시하지 않으며 서버에서도 역할을 검사한다.

## 주요 화면

### 대시보드

자산·설치·자료·읽지 않은 알림 건수를 카드로 보여 준다. 관리자에게는 카드 바로 아래에 **저장소 사용량** 패널(드라이브 사용률 막대, 사용/전체/여유, 포털 데이터·첨부·백업 합계, 사용량 관리 버튼)을 둔다. 그 다음 줄은 **오늘의 할 일 · 미완료 N건**(본인 메모, 최대 10건, 지난 날짜·오늘·예정 배지)과 **최근 프로젝트**(최근 수정 3건, 단계·상태 배지)이다. 그 아래는 최근 일주일 업무일지이며, 이어서 설치시작일이 최신인 설치 정보와 최근 수정된 자산을 보여 준다. 각 항목을 누르면 해당 상세 화면을 연다. 자산 기한은 상단 알림에서 확인한다.

### 자료 관리

왼쪽에서 단계 구분 없는 폴더 트리를 탐색한다. 탐색기처럼 작은 노란 폴더 아이콘, 하위 폴더 들여쓰기, 펼침·접기 화살표와 촘촘한 행 간격으로 표시한다. 폴더 이름을 누르면 해당 폴더를 열고 화살표를 누르면 하위 폴더만 펼치거나 접는다. 상단 버튼은 **폴더 생성**으로 표시한다. 현재 자료 영역의 빈 공간을 우클릭하면 현재 위치에 폴더를 만들고, 왼쪽 트리나 목록의 폴더를 우클릭하면 해당 폴더 안에 하위 폴더를 만든다. 같은 조작을 하위 폴더에서도 반복할 수 있다. 파일은 전체 자료와 모든 폴더에 등록하며 자료 영역에 파일을 끌어 놓아 추가할 수도 있다. 끌어 놓을 위치(자료 영역 또는 트리·목록의 폴더 행)는 점선으로 강조하고, 편집 권한이 있으면 자료 목록 아래에 등록 위치를 알려 주는 안내 상자를 표시한다. 목록의 유형은 모두 **폴더**로 표시한다. 파일명과 소속 폴더를 바꿀 수 있다. 폴더 이동은 하위 폴더와 파일을 함께 이동한다. 자기 자신 또는 자신의 하위 폴더로는 이동할 수 없다. 폴더 트리와 자료 목록 사이 경계를 끌어 트리 너비를 바꾸고(두 번 누르면 기본 200px), 자료 목록 표의 머리글 경계를 끌어 열 너비를 바꾸며, 경계를 두 번 누르면 기본 너비로 돌아간다.

### TO-DO List

독립 화면에서 **오늘의 할 일**을 연한 노란색 스티커 메모 카드로 표시한다. 빈 영역을 우클릭해 새 카드를 만들고 제목 구분 없는 한 입력칸에 바로 작성하면 자동 저장된다. 카드 오른쪽 아래를 끌어 크기를 수동 조절한다. 각 카드에는 날짜, 완료 체크, 파일 드래그 첨부, 삭제 버튼을 둔다. 별도 편집·추가 버튼은 두지 않는다. 완료 체크한 카드는 오른쪽 코르크 느낌의 **완료 보드**로 이동해 압정으로 붙인 작은 메모처럼 표시된다. 누르면 노란 메모가 큰 보기로 펼쳐지며 본문·첨부를 확인하고 할 일로 되돌리거나 삭제할 수 있다. 좁은 화면에는 보드를 할 일 아래에 배치한다. 왼쪽 영역의 검색창과 빈 안내 상자를 없애 메모지를 더 위쪽부터 사용할 수 있다. 메모는 로그인한 사용자에게만 보이며 다른 날짜의 메모도 남는다. 메모가 늘어도 업무관리의 업무일지 목록을 아래로 밀지 않는다.

넓은 화면의 완료 보드는 약 590×690px 크기로 오른쪽 상단에 배치한다. 보드 안의 완료 메모가 많아지면 보드 내부를 스크롤하며, 화면 폭이 좁아지면 보드의 고정 높이와 위쪽 당김을 해제한다.

### 업무관리

고객을 선택하면 업무일지 위에 저장된 고객 메모·연락처·첨부파일이 보인다. 고객 정보 영역에 파일을 끌어 놓아 첨부할 수 있다. 상세 창은 **진행 상태**, **업무 유형**(정기점검·장애지원·설치·Per Call·기타), **업무 타입**(원격·방문·기타)을 각각 표시한다. 새 기록은 업무 유형과 업무 타입을 모두 선택해야 한다. 목록에는 두 열을 따로 두고 각각 필터·정렬한다. 기존 기록의 빈 값은 미분류로 표시한다.

### 알림

자산 기한과 관리자용 업무 활동을 한 목록에서 보여 준다. 종류·제목과 함께 실제 알림 설명을 별도 줄에 표시한다. 자산 기한은 물품 보기, 업무 활동은 관련 메뉴 보기로 이동한다. 각각의 읽음 버튼은 해당 알림만 처리한다.

### 프로젝트 관리

설치 프로젝트와 기타 프로젝트를 구분한다. 설치 전·설치 중·설치 후 단계, 진행 상태, 예정/실제 일정, 고객사, 담당자, 위치, 메모를 기록한다. 저장하면 대화창을 닫고 목록을 갱신한다. 목록에서 프로젝트를 다시 열어 단계별 할 일을 추가하고 완료 상태를 표시한다. 수정 권한이 있는 사용자는 목록 오른쪽의 삭제 버튼으로 확인 후 프로젝트를 삭제할 수 있다. 기존 설치 정보와 연결할 수 있다.

### 사용량 관리

관리자 전용. 상단 카드에 드라이브 여유 공간·사용률, 포털 데이터 합계, 첨부파일 합계를 보여 준다. 로컬 드라이브 영역은 드라이브별 사용/전체/여유 용량과 막대를 표시하며 사용률 90% 이상이면 경고색으로 바꾼다(백업 폴더가 다른 드라이브에 있으면 함께 표시). 포털 데이터 파일 표는 DB·WAL·SHM·업로드 임시 폴더·실행 로그·백업 폴더의 위치와 크기를, 메뉴별 첨부파일 표는 자료 관리·설치·자산·고객·TO-DO 첨부의 파일 수와 용량을 보여 준다. **새로 고침**으로 다시 확인한다.

### 운영관리

관리자가 서버 실행 상태와 기본 데이터 건수를 확인하고, 이 화면에서 포털 설계도·화면 디자인·운영자 매뉴얼을 탭으로 읽는다. 운영자 매뉴얼 탭에서는 패널 오른쪽 위 **PDF 다운로드** 버튼을 표시한다. 백업/복구는 기존 전용 메뉴로 이동한다.
